# 构建与安装工具

## 目标

定制版每次出包要同时做三件事：用指定版本号构建 release APK、把 APK 复制到一个便于取用的目录、通过 adb 把 APK 覆盖安装到投影仪。把这三件事固化成 Makefile 目标，避免每次手拼 Gradle 命令、找 APK 文件名、拼 adb 参数。

## 执行步骤

1. 在仓库根目录新增 Makefile，提供 `build`、`export`、`install`、`version`、`clean` 五个目标。
2. 版本号通过 Gradle 的 `jellyfin.version` 属性传入，与 CI 用 `JELLYFIN_VERSION` 的做法一致，因此导出的 APK 文件名与 Gradle 产物保持一致（`jellyfin-androidtv-v<版本号>-release.apk`）。
3. `export` 把 APK 从 `app/build/outputs/apk/release/` 复制到导出目录，目录不存在时自动创建；产物文件名对不上时直接报错并列出实际产物，不静默产出空目录。
4. `install` 先 `adb connect` 再 `adb install -r` 覆盖安装，保留应用数据；安装失败时提示签名不一致的卸载命令。
5. Makefile 内自动补齐两个构建前提：未设置 `ANDROID_HOME` 时使用 `~/Library/Android/sdk`，未指向 JDK 21 时使用 Homebrew 的 `openjdk@21`（Gradle 的 toolchain 要求见 `.tools-versions`）。
6. 导出目录 `release/` 加入 `.gitignore`，避免 APK 进入版本库。

## 最终方案

| 命令 | 行为 |
| --- | --- |
| `make build` | 构建 release APK，产物留在 `app/build/outputs/apk/release/` |
| `make export` | 构建并把 APK 导出到 `release/` |
| `make export DEST=dist/` | 构建并把 APK 导出到 `dist/` |
| `make install` | 导出后通过 adb 覆盖安装到投影仪 `192.168.55.80:5555` |
| `make version` | 打印当前使用的版本号 |
| `make clean` | 执行 Gradle clean，不删除导出目录 |

可覆盖的变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `VERSION` | 环境变量 `JELLYFIN_VERSION`，否则 `0.20.0-seamless-v0.7` | 应用版本号，同时决定 APK 文件名 |
| `DEST` | `release` | APK 导出目录 |
| `DEVICE` | `192.168.55.80:5555` | 投影仪的 adb 地址 |

改动的文件：

- `Makefile`
- `.gitignore`
