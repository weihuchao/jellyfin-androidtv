# v0.3 播放器操作

## 目标

调整播放控制条的按钮排布、选中项与自动隐藏行为，让投影仪远程器只用方向键和 OK 键就能完成所有播放操作，且播放不会被意外暂停。

## 背景

官方 0.20.0 的播放控制条有三个不适合投影仪的行为：

1. 按钮排布是播放/暂停在上排首位，倍速在下排，与手思顺序不同；
2. 远程器按 OK 会切换播放/暂停，方向键在控制条上移动选中的位置不可控；
3. 进度条上按左右会进入 Leanback 的拖动弹窗，拖动开始时会暂停播放。

## 执行步骤

1. 重排 `CustomPlaybackTransportControlGlue.addMediaActions()` 中的按钮：上排为倍速、播放/暂停、字幕、下一集（后两者仅在媒体支持时出现），下排为缩放、画质、快退、快进。音轨、章节、上一集、直播电视项保留原有位置。
2. 在 glue 里记录上次点击和上次聚焦的 action，控制条出现时恢复选中，默认为倍速按钮。
3. 在 glue 里接管方向键：左右在同一排按钮之间移动，上下在按钮排与进度条之间移动，进度条上的左右改为快进快退（不走 Leanback 的拖动弹窗）。
4. 覆写 `onProgressBarClicked` 为空实现，覆写 `onReappear` 为空实现，避免框架自动触发播放/暂停与抢焦点。
5. 隐藏态按 OK 只显示控制条，不改变播放状态，并吞掉对应的 key up，防止此时体前按钮被误触发。
6. 控制条自动隐藏的等待时长统一为 `R.integer.playback_controls_auto_hide_timeout`，并保证任何按键都重新计时。

## 最终方案

| 场景 | 行为 |
| --- | --- |
| 上排按钮 | 倍速、播放/暂停、字幕选择、下一集，后者仅在媒体支持时出现，音轨、直播电视项在末尾 |
| 下排按钮 | 缩放、画质、快退、快进，上一集、章节、直播电视项在末尾 |
| 控制条刚出现 | 默认选中倍速；上次点击过的按钮优先恢复选中，其次用上次聚焦的按钮 |
| 左右键 | 在当前一排的按钮之间移动选中；在进度条上则是快进快退 |
| 上下键 | 在上排按钮、进度条、下排按钮之间移动选中 |
| 按 OK | 只调出控制条，不暂停也不继续播放 |
| 快进快退 | 按钮、远程器快进快退键、进度条左右均不中断播放 |
| 自动隐藏 | 最后一次操作后 3 秒隐藏 |

## 附录

### Leanback 按键分发路径

- `MainActivity.onKeyDown/onKeyUp` 只在视图层没有消费按键时才会被调用，播放界面的按键主要由视图层处理。
- `PlaybackSupportFragment` 把按键拦截器注册在 `RowsSupportFragment` 的 `VerticalGridView` 上（`BaseGridView.dispatchKeyEvent`），先交给 `setOnKeyInterceptListener` 注册的监听器（就是本项目的 `keyListener`），再派发给焦点视图。
- 控制条隐藏时焦点不在 transport row 内，方向键到不了 transport row，所以隐藏态的第一下方向键只负责唤出控制条，第二下才是移动选中。
- `PlaybackControlGlue.onKey` 会把 DPAD_CENTER 等按键映射到播放/暂停等 action，因此隐藏态按 OK 必须在进入视图层之前就被吞掉。

### 自动隐藏的两套计时

- Leanback 自带：`playbackControlsAutoHideTimeout`（恢复播放后）与 `playbackControlsAutoHideTickleTimeout`（每次方向键后）；
- Jellyfin 自带：`CustomPlaybackOverlayFragment.startFadeTimer()` 的 `mHideTask`。

两套计时都取同一个资源 `R.integer.playback_controls_auto_hide_timeout`，避免两边的隐藏时点不一致。

### 备选方案与取舍

| 方案 | 说明 | 结论 |
| --- | --- | --- |
| 隐藏时长 0.5 秒 | 严格按需求字面实现 | 未采用。实测控制条一出现就开始收回，完全无法操作，用户明确要求放宽 |
| 隐藏时长 3 秒 | 远程器可以完成一次判断后的按键 | 采用。与 Leanback 默认的 `playbackControlsAutoHideTimeout` 一致 |
| 进度条左右用 Leanback seek ui | 官方行为 | 未采用。seek ui 开始时会 pause，违反需求 5 |
| 隐藏态按 OK 播放/暂停 | 官方行为 | 未采用。需求 4 要求 OK 只显示控制条 |
| 只记录上次点击的按钮 | 严格对应需求 2 | 部分采用。另增上次聚焦的按钮作为兜底，因为自动隐藏会丢失焦点位置 |

### 实现细节

- 传输行的结构：上排 `controls_dock`（最多 7 个）、中排 `playback_progress`（SeekBar）、下排 `secondary_controls_dock`（最多 7 个）。
- 三个焦点组在 `createRowViewHolder` 里抓取，导航逻辑直接对这三个容器做光标移动，不依赖 `focusSearch`（API 28 上不可靠）。
- `onReappear` 需要被覆写为空实现，否则 Leanback 会把焦点抢回进度条。
- `onProgressBarClicked` 需要被覆写为空实现，否则点击进度条会触发 Leanback 默认的播放/暂停。
